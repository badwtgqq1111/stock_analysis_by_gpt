# 统计学五大反常识定理与量化交易应用

> 高维几何、收缩估计、随机过程、遍历性、极值理论——五个颠覆直觉的统计洞察及其在量化建模中的实践指南。

---

## 1. 维度诅咒 (Curse of Dimensionality)

### 直觉颠覆

三维空间中的经验在高维空间中全面崩塌。核心现象：

- **球体悖论**：10 维空间中，内切于超立方体的超球体体积仅占超立方体的 **0.25%**。高维空间几乎全部是"角落"——数据点如星辰贴附在球壳表面，中心反而空无一物。
- **距离失效**：维度升高时，任意两点间距离趋同。最近邻与最远邻的比值趋向 1，KNN 等在低维中有效的算法彻底失效。
- **数据稀疏**：要在 10 维空间中维持与 1 维相同的采样密度，需要 `10^d` 倍的样本量。

### 量化实践

```
问题：特征数量 d ↑ → 模型需要指数级样本才能避免过拟合
方案：严格控制特征维度，用正则化压缩空间
```

| 技术 | 作用 | 本项目对应 |
|------|------|-----------|
| LASSO (L1) | 将无关特征系数压缩到 0 | `max_features` 参数 (默认 0=全部) |
| 最大特征数限制 | 硬截断，防止维度膨胀 | `max_features` > 0 时启用 |
| 递归特征消除 (RFE) | 逐步剔除最不重要特征 | LightGBM feature_importances_ 排序 |
| PCA 降维 | 保留方差最大的方向 | 待引入 |

**经验法则**：特征数 < `n_samples / 10`。对于 668 只 HK 股票，365 日回溯期有效样本约 668×195≈130K 行，特征上限建议 ~150–200。当前 alpha158_hk 为 198 列——已在边界。

## 2. 詹姆斯-斯坦悖论 (James-Stein Paradox)

### 直觉颠覆

估计 3 个以上**互不相关**的参数时，向任意常数**收缩**（shrinkage）后的估计量比各自单独的样本均值具有**更低的期望平方误差**。

```
μ_i = 第 i 个参数的样本均值
θ̂_i^JS = μ̄ + (1 - (k-3)σ²/Σ(μ_i - μ̄)²)(μ_i - μ̄)

k ≥ 3 时，MSE(θ̂_JS) < MSE(μ)  对所有 μ 成立
```

三件完全无关的事——北京降雨量、腾讯股价、吃饺子的个数——合并到同一框架下估计，反直觉地降低了**每一项**的误差。

### 量化实践

```
问题：单只股票的收益估计噪声极大，独立估计不稳定
方案：向市场均值或行业均值收缩，牺牲无偏性换取稳定性
```

**投资组合中的应用**：

| 方法 | 描述 |
|------|------|
| **均值收缩** | 单只股票的历史收益向整体市场均值收缩，降低极端值权重 |
| **协方差收缩** | Ledoit-Wolf 方法：样本协方差向单位矩阵收缩，改善逆矩阵稳定性 |
| **贝叶斯先验** | 用 ~0 先验均值做 `Ridge` 回归（等价于 L2 正则化） |

当前 `factor_engine` 已支持 `ridge_factors` 参数，本质即为 James-Stein 型收缩。

**Goldman Sachs 的实践**：在 Black-Litterman 模型中，用市场均衡收益作为先验，将投资者观点向先验"收缩"，避免极端配置。

## 3. 反正弦定律 (Arcsine Law)

### 直觉颠覆

公平的随机游走（无漂移）中，序列处于**正半轴**的时间比例并非正态分布在 50% 附近，而是呈 **U 型分布**：

```
P(正半轴时间比例 ≤ x) = (2/π) · arcsin(√x)

极端情况概率：
  正半轴 < 2.5% 的时间: ~10%
  正半轴 > 97.5% 的时间: ~10%
  "平衡"（40-60%）仅约 20%
```

赌场中"一直赢"或"深套其中"不是运气——是数学必然。技术图表上的"趋势"大概率是随机游走的 U 型分布制造的幻觉。

### 量化实践

```
问题：价格走势可能是随机游走，趋势线看似连贯实则随机
方案：警惕随机游走假象，用统计检验验证趋势，设置硬性止损
```

| 技术 | 作用 |
|------|------|
| **方差比检验** (Variance Ratio Test) | 检验收益率是否满足随机游走。`VR(k)=Var(r_{t,t+k})/(k·Var(r_t))`，VR≠1 则拒绝随机游走 |
| **Hurst 指数** | H > 0.5 趋势持续，H < 0.5 均值回归。比肉眼判断趋势可靠 |
| **硬止损** | 无论"直觉"多强，触发止损就离场。应对反正弦定律的深套侧 |

当前系统中 `Risk_Penalty` 和 `Max_Drawdown_Factor` 已隐含止损逻辑，但可以加强为严格的硬止损规则。

## 4. 遍历性破缺 (Ergodicity Breaking)

### 直觉颠覆

遍历性假设"**集合平均 = 时间平均**"在金融中普遍不成立，因为收益是**乘法过程**而非加法过程。

```
赌局：50% 翻倍 (×2)，50% 减半 (×0.5)
集合平均（算术）：0.5×2 + 0.5×0.5 = 1.25  ← 看似有利
时间平均（几何）：(2×0.5)^(1/2) = 1.0      ← 实际不赚不赔
长期乘法：lim (1.25)^n × exp(-σ²/2 × n) → 0  ← 必然破产
```

反复参与算术期望为正的赌局，长期却必然破产——因为少数连续亏损的乘法效应不可逆。

### 量化实践

```
问题：均值-方差优化最大化算术收益，但投资是乘法过程
方案：用凯利公式优化对数财富增长率，替代均值-方差框架
```

**凯利公式 (Kelly Criterion)**：

```
f* = (p·b - q) / b    其中 p=胜率, b=盈亏比, q=1-p

对数财富增长：E[log(W)] = (1 + f·r) 的几何平均
```

| 对比 | 均值-方差 | 凯利公式 |
|------|----------|---------|
| 优化目标 | `max(E[R] - λ·Var(R))` | `max(E[log(1 + f·R)])` |
| 加/乘法 | 加法 | **乘法**（匹配实际） |
| 极端处理 | 方差惩罚 | **天然规避破产风险** |
| 半凯利 | — | 半凯利 (f*/2) 牺牲 25% 收益换 50% 波动降低 |

**当前系统**：`backtest_portfolio` 的 `weighting_mode="equal_weight"` 等价于全仓平均分配。可以增加 `kelly` 模式，根据每个信号的胜率/盈亏比动态分配仓位。

## 5. 厚尾分布风险 (Fat-Tailed Distributions)

### 直觉颠覆

金融收益率并非正态分布。极端事件的概率呈**幂律衰减**而非指数衰减：

```
正态分布：P(|X| > 4σ) ≈ 1/15,787    ← 六西格玛事件永不发生
幂律分布：P(|X| > 4σ) ≈ 1/200       ← 每隔几年就发生

2008 年金融危机中，"百年一遇"的波动连续发生多次
```

柯西分布（t 分布 df=1）的**方差无穷大**——意味着以方差为核心的风控模型（VaR、均值-方差优化）在理论上就是失效的。

### 量化实践

```
问题：正态假设下的 VaR 严重低估尾部风险
方案：用极值理论 (EVT) 建模尾部，放弃正态分布假设
```

| 技术 | 描述 |
|------|------|
| **极值理论 (EVT)** | 用广义帕累托分布 (GPD) 单独建模分布尾部。`P(X > u + x | X > u) ≈ (1 + ξx/σ)^{-1/ξ}` |
| **Peaks-Over-Threshold (POT)** | 设定阈值 u，只对超过 u 的极端值建模 |
| **Expected Shortfall (ES)** | 替代 VaR：`ES_α = E[L | L > VaR_α]`，考虑尾部所有损失而不只是分位点 |
| **Student-t 拟合** | 用 t 分布替代正态，自由度 df 越低尾部越厚。金融危机期间 df≈3-5 |
| **Cornish-Fisher 展开** | 用偏度和峰度修正正态分位数 |

**当前系统**：`Risk_Penalty` 和 `Max_Drawdown_Factor` 基于滚动标准差，隐含假设了正态分布。可以增强为：
- 用 **历史模拟 ES** 替代标准差
- 用 **GARCH** 捕捉波动率聚类
- 对尾部 5% 的损失单独建模

## 五项原则速查

| # | 定理 | 核心教训 | 量化行动 |
|---|------|---------|---------|
| 1 | 维度诅咒 | 特征不是越多越好 | L1 正则化，限制 `max_features` |
| 2 | James-Stein | 个人估计不可靠，向群体收缩 | `ridge_factors`，Ledoit-Wolf 协方差 |
| 3 | 反正弦定律 | 趋势可能是随机游走幻觉 | 方差比检验，硬止损 |
| 4 | 遍历性破缺 | 算术平均≠长期结果 | 凯利公式，半凯利保守仓位 |
| 5 | 厚尾风险 | 正态假设低估极端事件 | EVT，Expected Shortfall，GARCH |
