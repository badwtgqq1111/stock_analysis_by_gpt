# 国泰君安 191 Alpha 因子库

## 来源

国泰君安证券 2017 年 6 月研报 **《基于短周期价量特征的多因子选股体系——数量化专题之九十三》**。

原始回测：**T+2 换仓**，年化超额收益约 **50.2%**，最大回撤 **5.9%**（中证 500 对冲）。

> 注意：市场上常将这些因子称为 "WorldQuant 191 因子"，但实际来源是国泰君安。WorldQuant 另有自己的 101 公式化 Alpha 因子（2015 年发布）。

## 核心运算函数

| 函数 | 定义 |
|------|------|
| `ABS(x)` | x 的绝对值 |
| `LOG(x)` | x 的自然对数 |
| `RANK(x)` | 横截面升序排名（百分比，0~1） |
| `TS_RANK(x, n)` | 序列 x 末位值在过去 n 天的时序排名（0~1） |
| `DELTA(x, n)` | x 的一阶差分：x_i - x_{i-n} |
| `DELAY(x, n)` | x 滞后 n 期 |
| `CORR(x, y, n)` | x 和 y 过去 n 天的 Pearson 相关系数 |
| `COV(x, y, n)` | x 和 y 过去 n 天的协方差 |
| `SUM(x, n)` | x 过去 n 天求和 |
| `MEAN(x, n)` | x 过去 n 天均值 |
| `STD(x, n)` | x 过去 n 天标准差 |
| `SMA(x, n, m)` | x 的 SMA 平滑：SMA_t = (x_t * m + SMA_{t-1} * (n - m)) / n |
| `MAX(x, n)` | x 过去 n 天最大值 |
| `MIN(x, n)` | x 过去 n 天最小值 |
| `TS_MAX(x, n)` | 同上（时序最大值） |
| `TS_MIN(x, n)` | 同上（时序最小值） |
| `DECAYLINEAR(x, n)` | 线性衰减加权平均，权重为 n, n-1, ..., 1 |
| `REGRES(x, y, n)` | x 对 y 过去 n 天的线性回归斜率 |
| `PROD(x, n)` | x 过去 n 天连乘 |
| `SIGN(x)` | x 的符号（正为 1，负为 -1，零为 0） |
| `SUMIF(x, n, cond, y)` | 条件求和：过去 n 天中满足 cond 的 y 值求和 |
| `COUNT(cond, n)` | 过去 n 天中满足 cond 的天数 |
| `TR(x)` | 当日真实波幅：max(high-low, abs(high-prev_close), abs(low-prev_close)) |

## 代表性因子公式

### Alpha001（量价背离）
```
(-1 * CORR(RANK(DELTA(LOG(vol), 1)), RANK((close - open) / open), 6))
```
成交量变化与日内收益的负相关——量价背离信号。

### Alpha006（开盘跳空反转）
```
(-1 * TSRANK(DELTA((open * 0.85 + high * 0.15), 1), 4))
```
开盘价上跳后倾向反转。

### Alpha012（VWAP-开盘溢价）
```
(SIGN(DELTA(vol, 1)) * (-1 * DELTA(close, 1)))
```
量增价跌的动量信号。

### Alpha020（收盘延迟比较）
```
(((-1 * RANK(open - DELAY(high, 1))) * RANK(open - DELAY(close, 1))) * RANK(open - DELAY(low, 1)))
```
开盘价相对昨日高/收/低的位置，三因子交互。

### Alpha028（波动率加权反转）
```
(SCALE(((CORR(high, MEAN(close, 5), 9) + ((high - close) / (high - low))) - (DELAY(close, 1) - close)))
```
相关系数与日内跌幅的交织。

### Alpha032（成交量价格相关性）
```
(SCALE(((SUM(close, 7) / 7) - close)) + (20 * CORR(vwap, DELAY(close, 5), 230)))
```
短期均值回归 + VWAP-收盘价长期相关性。

### Alpha041（VWAP 波动反转）
```
((((high * low) ^ 0.5) - vwap) * -1)
```
几何均价与 VWAP 的偏离——均值回归。

### Alpha046（收盘缩短期均值回归）
```
((MEAN(close, 3) + MEAN(close, 6) + MEAN(close, 12)) / 3 - close) / close * -1
```
三重均线聚合与现价的偏离。

### Alpha053（日内极端值反转）
```
COUNT(close > DELAY(close, 1), 12) / 12 * (RANK((high - close) / (high - low)) * -1 * (RANK(LOW_DIFF) ^ 0.5))
```
连涨天数比例 × 日内上影线长度。

### Alpha067（收盘动量强度）
```
RANK(DELTA((close - MEAN(close, 8)), 1)) * -1
```
收盘价偏离其 8 日均值的变化反向。

### Alpha081（放量上涨强度）
```
SMA(MAX(vol, 5), 5, 1) * RANK(DELTA(close, 5))
```
5 日最大成交量 × 5 日价格变化排名。

### Alpha085（高成交额换手）
```
(TS_RANK(vol / MEAN(vol, 20), 20) * TS_RANK((-1 * DELTA(close, 7)), 8))
```
放量 + 下跌幅度的交互。

### Alpha101（VWAP-收盘收敛）
```
((RANK(CORR(close, SUM(MEAN(vol, 30), 37), 15)) < RANK(CORR(RANK(high * low), RANK(MEAN(vol * vwap, ...)), 11))) * -1)
```
两组相关性的比较——价格-成交量协同是否变化。

### Alpha114（日内波动加权反转）
```
((RANK(DELAY(((high - low) / (SUM(close, 5) / 5)), 2)) * RANK(RANK(vol))) / ((high - low) / (SUM(close, 5) / 5)) / vwap - close)
```
历史波动排名 × 成交量排名 / 当前波动。

### Alpha121（VWAP 趋势偏离）
```
((RANK(vwap - MIN(vwap, 12))) ^ TSRANK(CORR(TSRANK(vwap, 20), TSRANK(MEAN(vol, 60), 20), 18), 3)) * -1
```
VWAP 低位排名 ^ VWAP-成交量相关性排名——非线性惩罚。

### Alpha155（成交量反转）
```
SMA(vol, 13, 2) - SMA(vol, 27, 6) - MEAN(DELAY(vol, 9), 3) - CORR(MEAN(close, 3), MEAN(vol, 27), 5)
```
短/中/长三窗口量价偏离聚合。

### Alpha160（缩量下跌强度）
```
SMA((CLOSE <= DELAY(CLOSE, 1) ? STD(CLOSE, 20) : 0), 20, 1)
```
仅下跌日计入波动，上涨日波动为 0——非对称波动强度。

### Alpha172（高低价均值回归）
```
MEAN(close - DELAY(close, 1), 14) * (CORR(DELAY(high - low, 1), SUM(MEAN(close, 5), 10), 5) + RANK(high - low) / high - low)
```
14 日收益均值 ×（波动相关性 + 波动排名/幅度）。

### Alpha191（量价协同突破）
```
((CORR(MEAN(vol, 20), low, 5) + ((high + low) / 2 - close)) * -1)
```
成交量均值与低点相关性 + 日内中心价偏离——突破前量价背离。

## 使用建议

1. **中性化处理**：使用前应对行业和市值做中性化，消除系统性偏差
2. **因子筛选**：191 个因子存在较高的同质性（共用相同函数组合），建议先跑 IC 筛选，仅保留 IR>0.3 的因子
3. **去冗余**：同类因子相关性通常 >0.6，可用 PCA 或 Ridge 压缩到 20-40 个有效维度
4. **组合权重**：不推荐等权，使用 ICIR 加权或 LightGBM 自动特征选择效果更好
5. **调仓频率**：原始研报推荐 T+2 换仓，实际可根据流动性调整为日频或周频
6. **回测基准**：建议对中证 500 或中证 1000 成分股回测（原始研报使用中证 500 对冲）
