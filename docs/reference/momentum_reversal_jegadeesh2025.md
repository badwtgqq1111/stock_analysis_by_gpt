# Short-Term Reversals and Longer-Term Momentum around the World: Theory and Evidence

> Jegadeesh, N., Luo, J., Subrahmanyam, A., & Titman, S. (2025)
> *Review of Financial Studies*, 38(12), 3673–3728
> [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4069575) | [DOI](https://doi.org/10.1093/rfs/hhaf057)

## 1. 核心贡献

该论文建立了一个多期理论模型，解释了**短期反转如何过渡到长期动量**的完整机制。这统一了之前被视为独立异象的反转效应（Jegadeesh 1990）和动量效应（Jegadeesh & Titman 1993）。

## 2. 模型框架

三类投资者互动产生反转→动量过渡：

| 投资者类型 | 行为 | 产生的效应 |
|-----------|------|-----------|
| **噪声交易者**（短视+长视） | 随机买卖，制造价格压力 | 短期反转 |
| **知情投资者** | 基于基本面交易，纠正错误定价 | 使动量持续 |
| **非知情投资者**（过度自信） | 对自己未产生的信息反应不足 | 长期动量 |

**核心机制**：
1. 噪声交易者的订单流将价格推离基本面 → **短期反转**（1 个月）
2. 信息逐渐扩散，非知情投资者逐步调整估值 → 中间"空白期"（2 个月）
3. 价格朝基本面方向持续调整 → **长期动量**（3–12 个月）

## 3. 三个新预测与实证

### 预测 1：盈利公告后反转效应减弱

市场在盈利公告期接收更多信息，价格反应不足（underreaction）更强，抵消了噪声交易导致的反转。

| 市场 | 效果 |
|------|------|
| 美国（1931–2020） | 反转效应在公告后减弱约 **2/3**（φ≈+0.025, t>7） |
| 国际（22 发达+27 新兴） | 同样的减弱幅度，高"盈利质量"国家更明显 |

### 预测 2：反转与动量利润负相关

更多噪声交易 → 更强反转 + 更弱动量。因此反转和动量利润应呈负相关。

| 维度 | 结果 |
|------|------|
| 跨国截面回归 | α₁≈**-0.166**（t<-6），动量利润增加 1σ → 反转利润减少 0.19σ |
| 国内时间序列 | ~90% 的国家呈负相关，平均 ρ = **-0.216** |
| 跨国截面相关 | ρ = **-0.313** |

### 预测 3：噪声交易更多时反转更强

| 代理变量 | 结果 |
|---------|------|
| 低机构持股国家 | 反转利润 0.45%/月 vs 高机构持股国家更弱 |
| 零售订单失衡（TAQ 数据） | 零售 OIB × 滞后收益交互项 φ≈**-0.11**（t=-4.78） |

## 4. 因子构建细节

### 反转因子
- **形成期**：t-1 月收益
- **持有期**：t 月
- **方向**：买入上个月输家，卖出赢家（预期反转）
- **关键**：必须**跳过盈利公告月**以获得更强信号

### 动量因子
- **形成期**：t-12 至 t-2 月累计收益（**跳过 t-1 月**）
- **持有期**：t 月
- **方向**：买入过去赢家，卖出输家（预期延续）
- **为什么跳月**：跳过 t-1 月可以消除噪声交易引起的反转污染，动量更强

### 收益过渡模式
```
滞后 1 月：  显著为负  (ρ ≈ -0.045)    ← 反转主导
滞后 2 月：  不显著                      ← 空白期
滞后 3-12 月：显著为正                  ← 动量主导
```

## 5. 国际证据

### 覆盖范围
- **22 个发达市场** + **27 个新兴市场**
- 时间跨度：1991–2020
- 反转和动量模式在所有市场中稳健存在

### 跨国异质性（影响动量强度的因素）

| 因素 | 对动量的影响 | 机制 |
|------|-------------|------|
| 机构持股比例高 | 动量更强 | 噪声交易更少，反转污染更弱 |
| 个人主义文化（Hofstede） | 动量更强 | 过度自信更普遍 |
| 不确定性规避 | 反转和动量都受影响 | — |
| 订单流持续性低 | 动量利润高 ~25%（1.6%/月 vs 1.2%/月） | 信息扩散更渐进 |
| 低波动市场 | 动量更强 | 投资者恐惧感较低 |
| 上涨市场 | 动量更强 | 投资者盈利后更自信 |

### 动量利润基准

| 市场 | 月均 WML 收益 |
|------|--------------|
| 全部非美国 | **0.89%** |
| 发达市场（非美国） | **0.85%** |
| 新兴市场 | **0.74%** |

> 来源：Goyal, Jegadeesh & Subrahmanyam (2024), *Review of Finance*

### 6.2 可新增的因子方向

基于论文的三个预测，可以考虑：

1. **盈利公告反转衰减因子** — 识别盈利公告后的反转减弱期，与其他反转信号交互
2. **噪声交易代理因子** — 用换手率波动或散户订单失衡作为反转强度的调节变量
3. **反转-动量对冲信号** — 当反转和动量信号方向一致时（很少见），信号可信度更高

### 6.3 对回测的启示

- **持有期选择**：1 个月反转、3–12 个月动量，中间 2 个月是"信号空白期"——60 日持有期（当前默认）跨过了空白期，可能混合了反转和动量的相反信号
- **跳月设计**：当前 `forward_return_60` 没有跳过 t-1，会被反转效应污染
- **HK 市场特殊性**：作为新兴市场，动量利润（0.74%/月）低于发达市场，但散户占比高意味着**反转效应可能更强**
