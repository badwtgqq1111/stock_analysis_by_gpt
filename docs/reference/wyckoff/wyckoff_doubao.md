## 一、四阶段量化判定规则（可直接写进Python）
### 1）主力吸筹 Accumulation（底部建仓）
**特征**
1. 前期持续下跌，进入低位箱体震荡
2. 成交量：大部分时间地量，间歇出现放量阳线（试盘扫货），放量后又缩量回落，低点不再创新低
3. 价格：小阴小阳为主，急跌之后快速收回（不有效跌破箱体下沿）
4. 资金：大单持续净流入、A/D（收集派发线）拐头向上，筹码集中度逐步抬升
**量化条件示例**
- 20日振幅＜12%，股价处于近1年低位区间
- 放量阳线当日大单净买入 / 流通市值 >阈值
- 低点不再创新低（N日最低＞前N日最低）

### 2）主力拉升 Markup
**特征**
1. 放量突破吸筹箱体上沿
2. 量能温和放大，价格重心持续上移
3. 回调缩量，回踩不跌破突破位
4. A/D持续上行，筹码峰上移
**量化条件**
- 收盘价向上突破箱体上轨，突破当日成交量＞20日均量
- 均线多头排列

### 3）主力洗盘 Distribution（中继洗盘，不是出货）
**特征**
1. 拉升一段后震荡回撤
2. **缩量下跌**（核心区分点：抛压是散户，主力筹码没跑）
3. 下跌幅度可控，守住关键支撑位（成本线/突破位）
4. 快速止跌，重新收阳线
> ❗重点：洗盘=缩量回调；出货=放量滞涨
**量化条件**
- 回撤幅度 5%~12%
- 回调成交量明显小于拉升段成交量
- 不有效跌破20日均线/前期突破平台

### 4）主力派发 Distribution（高位出货）
**特征**
1. 高位震荡，价格涨不动，但成交量持续放大（放量滞涨）
2. 长上影、十字星频繁出现
3. A/D指标和股价**顶背离**：股价创新高，资金不再创新高
4. 大单净流出持续，筹码峰从底部转移到高位
**量化条件**
- 股价处于阶段高位
- 量增价平/量增价跌
- A/D连续多日下行

## 三、关键坑（非常重要，量化回测很容易踩）
1. **交易所“大单”划分标准是人为定义**：主力可以拆成无数小单，伪装成散户，直接看主力净流入很容易假信号
2. 威科夫本身是主观形态理论，量化之后**信号大量重叠、误报极多**，单独用胜率一般；需要叠加板块、流动性、基本面因子一起过滤
3. 吸筹、洗盘边界模糊，一段K线可能同时触发多个条件，状态跳变频繁
4. 回测容易未来函数：筹码分布、WINNER函数有潜在未来风险
