## 〇、概念澄清：研报里的"概率云"到底是什么

**关键纠正**：这里的"概率云"**不是**指"未来价格落在某区间的概率锥（probability cone / conformal prediction）"，而是借用量子力学的比喻，指**事件识别本身的概率化**：

- 传统威科夫是**主观判读**——分析师肉眼看图判断"这是 Spring 还是 SC"。
- 研报的做法：在**每一根 K 线**上，对所有候选威科夫事件（PS、SC、Spring、UT…）各算一个 **0–100% 的"似然度"**。同一根 K 线上多个事件的概率并存，就像电子云一样弥散——这就是"概率云"。
- 最后取概率最高且 **绝对似然度 ≥ 60%** 的那个事件，**"坍缩"**为该 K 线的确定形态（波函数坍缩的比喻）；若无一达标，则认为该 K 线无显著形态。

所以这篇研报解决的是"**从主观到量化**"——把威科夫的离散事件判读，变成一套**确定性公式 + sigmoid 概率映射**，而非机器学习黑箱，也非价格分布预测。

> 我在初版文档里把"概率云"误解为 conformal prediction 式的价格预测锥，这是错的。研报的概率云是**事件分类的软标签**。原 conformal prediction 文献作为"延伸方向"保留在第四节，但不要混为一谈。

## 一、威科夫理论基础（研报第 1-2 节）

### 1.1 一句话与四大原则

> 威科夫思想：**基于主力资金的吸筹与派发行为判断市场方向。**

| 原则 | 含义 |
|---|---|
| 供求关系原则 | 关注量价特征的目的是**识别吸筹/派发阶段**，而非利用技术形态本身交易 |
| 因果关系原则 | "因"=趋势出现前的准备过程，"果"=趋势的形成。"横有多长，竖有多高" |
| 努力与结果原则 | **放量滞涨**→主力可能在派发；**放量滞跌**→主力可能在吸筹；均预示趋势停止/反转 |
| 右进左出原则 | 多空开单。A股不存在此情况（无法做空个股） |

### 1.2 吸筹过程的五阶段（Phase A-E）

- **A（止跌）**：卖方主导，振幅大、成交量大。成功的二次测试可创新低，但卖盘、振幅、成交量都减少。卖出密集区最低点、二次测试点、自动反弹最高点 → 界定横盘振荡范围。
- **B（建仓）**：主力低价吸筹 + 高位做空试探市场动力。早期波动范围与成交量都大，卖盘衰竭则 B 结束。
- **C（测试）**：继续测试卖盘。两种情况——① Spring（弹簧效应）的成功测试（**高成功率交易机会**）；② 发生在支撑线上方（较难识别）。
- **D（拉升）**：需求 > 供给，放量上涨振幅变大，缩量回调振幅变小 = 加仓/买入机会。
- **E（趋势）**：离开横盘震荡，需求控制市场，回调短暂且不明显。

## 二、量化框架（研报第 3 节）—— 本文核心

研报强调：**威科夫不建议机械地定义事件**，因此辅助线偏规则化，事件形态才用概率化。整体分三层：定义波段 → 定义趋势线/水平线 → 事件形态概率云。

### 2.1 定义波段（规则化，非概率）

- **起点**：上一个已确认波段（涨/跌）至今的 Close 最高/最低点。
- **新上涨波段确认**：MACD > 0 且当前 K 线 Close 为起点以来最高点。
- **新下跌波段确认**：MACD < 0 且当前 K 线 Close 为起点以来最低点。
- 波段确认后，旧起点固定为旧波段终点，最新 K 线成为新起点（浮动）。

### 2.2 定义趋势线与水平线（规则化）

> 趋势线用于趋势，水平线用于盘整。

| 形态 | 判定（最近两顶/两底端点） |
|---|---|
| 上涨趋势 | 两顶上升 + 两底上升 |
| 下跌趋势 | 两顶下降 + 两底下降 |
| 收缩盘整 | 两顶下降 + 两底上升 |
| 扩张盘整 | 两底上升 + 两顶下降 |

说明要点：
- **波段 vs 趋势**：新波段端点需下一波段确认；趋势/盘整定义未必需要最新波段端点，可随价格持续调整。
- 趋势/盘整的定义**不是为了刻画当下状态，而是为了确定该关注哪类辅助线和思考角度**。
- 趋势下画趋势线，盘整下画水平线。水平线 = 最近四个已确认端点 + 当下未确认波段最高/最低点的水平延伸。

### 2.3 事件形态概率云（研报第 3.3 节）—— 全部公式

> 目的：跟踪事件形态，确认市场吸筹/派发到了哪个阶段。
> 记号：`sig(x)` = sigmoid 函数；"分位数"指区间/趋势以来的历史分位；不满足前置条件则概率为 0%。

**下跌趋势及转盘整后（判断下跌是否终止、上涨是否到来）**

| 事件 | 公式 / 判定 |
|---|---|
| SOT(Down) | 波段顶端点处，临近三个波段底端点持续下降但距离缩短 → 满足即 100%，否则 0% |
| ASY | 价格向上突破供应线/阻力线 → 满足即 100%，否则 0% |
| PS | 下跌波段中 `sig((Close/Low-1-0.02)*10+0.5) * sig(Close/Low 分位数[≥3根K线后]) * sig(下跌以来成交量分位数)`（实体阳线或长下影线都算） |
| SC | 下跌波段中 `sig((-(Close/Open-1)-0.04)*20+0.5) * sig(下跌以来成交量分位数)` |
| AR&ST(Down) | 连续上涨后的连续下跌停止后，`sig((累计上涨幅度/累计下跌幅度)/10+0.5) * sig((上涨均量/下跌均量)/5+0.5)` |
| TSO | 单 K 线突破所有支撑线且后续 K 线 Close 不低于其 Low，`sig(区间以来成交量分位数)` |
| SPRING | `sig(下影线长度/K线其余长度/3) * sig(区间以来成交量分位数) * min(0.01/收盘与最近水平线百分比距离, 1)` |
| LPS | 连续上涨后连续下跌结束时，`sig((下跌低点Close/区间最低Close-1)*10+0.5) * sig((上涨均量/下跌均量)/5+0.5)` |
| JOC | 突破关键阻力线（确认度前三），`sig((Close/Open-1)*10+0.5) * sig(区间成交量分位数)` |

**上涨趋势及转盘整后（判断上涨是否终止、下跌是否到来）**

| 事件 | 公式 / 判定 |
|---|---|
| SOT(Up) | 波段顶端点处，临近三个波段顶端点持续上升但距离缩短 → 满足即 100% |
| AS | 价格向下突破需求线/支撑线 → 满足即 100% |
| PSY | 上涨波段中 `sig((High/Close-1-0.02)*10+0.5) * sig(High/Close分位数[≥3根K线后]) * sig(上涨以来成交量分位数)`（实体阴线或长上影线都算） |
| BC | 上涨波段中 `sig(((Close/Open-1)-0.04)*20+0.5) * sig(上涨以来成交量分位数)` |
| AR&ST(Up) | 连续下跌后的连续上涨停止后，`sig((累计下跌幅度/累计上涨幅度)/10+0.5) * sig((下跌均量/上涨均量)/5+0.5)` |
| UT | `sig(上影线长度/K线其余长度) * sig(区间以来成交量分位数) * min(0.01/收盘与最近水平线百分比距离, 1)` |
| LPSY | 连续下跌后连续上涨结束时，`sig((区间最高Close/上涨高点Close-1)*10+0.5) * sig((下跌均量/上涨均量)/5+0.5)` |
| BOI | 下跌波段突破上一个底端点 → 满足即 100% |

**买入超买 OB**
- OB(Line)：价格向上突破超买线 → 满足即 100%
- OB(Up)：`sig((Close持续抬升数+0.5)/10) * sig(上涨以来成交量分位数)`

**超卖 OS**
- OS(Line)：价格向下突破超卖线 → 满足即 100%
- OS(Down)：`sig((Close持续降低数+0.5)/10) * sig(下跌以来成交量分位数)`

**强势信号 SOS**
- 3H：连续 3K 线更高 High/Low/Close，`sig((1-std(3K线Close/Open-1)*30)) * sig(3K线累计绝对涨幅*10)`
- VDB：阳线下 `sig(区间K线实体长度分位数) * sig(K线实体/K线总长度/2+0.5) * sig(区间成交量分位数)`
- OKR(Up)：连续 2K 线阳包阴（高点更高、低点更低），收盘在中部以上 → 满足即 100%

**弱势信号 SOW**
- 3L：连续 3K 线更低 High/Low/Close，`sig((1-std(3K线Close/Open-1)*30)) * sig(3K线累计绝对跌幅*10)`
- VSB：阴线下 `sig(区间K线实体长度分位数) * sig(K线实体/K线总长度/2+0.5) * sig(区间成交量分位数)`
- OKR(Down)：连续 2K 线阴包阳（高点更高、低点更低），收盘在中部以下 → 满足即 100%

**概率坍缩规则**：取多种候选事件中概率最高且**绝对似然度 ≥ 60%** 者为该 K 线的最可能事件形态；若无满足条件者，则认为当下 K 线无显著形态特征。

## 三、因子构建与回测（研报第 4-5 节）

### 3.1 数值映射

把事件形态转为多空分数：
- **吸筹指标**（下跌转盘整后）、**强势信号 SOS**、**超卖 OS** → 统一映射为 **+1 分**
- **派发指标**（上涨转盘整后）、**弱势信号 SOW**、**超买 OB** → 统一映射为 **-1 分**
- 加权方式：**半衰期 10 个交易日的指数加权**，每根 K 线得到其过去 20 个临近事件形态的综合打分。

### 3.2 两个因子

**WSO（Wyckoff Score Original）**：上述指数加权综合打分，直接作为因子。

**WSS（Wyckoff Score Selected）**：基于规律统计的精选信号——
- 统计**至多 6 个形态位**在未来 1/3/5/10/20/30 交易日的平均收益率、胜率、赔率；限定纳入形态**至少发生 100 次以上**，统计区间 **2010-2022**。
- 形态位增加到 **6 个时，最高胜率达 90%**。
- 在每个 (形态, 未来窗口) 下，仅保留**胜率 ≥ 55% 且赔率 ≥ 1.08** 的多空信号（"有效信号"），以信号胜率作为分数（空头为负）。
- 每日得到 1×30 多空分数，滚动 30 天对齐 → 30×30 矩阵，半衰期 10 日指数加权 → 每日最终分数。

### 3.3 实验结果

| 因子 | 选股能力 | 个股择时（全A，双边 0.3% 费率，等权配置） |
|---|---|---|
| **WSO** | 选股效果有限：2010-2022 双周频，**年化 IC 0.07，ICIR 1.11**，十分组单调性一般 | WSO>0 做多、<0 做空，2010-2024.6 **年化收益 16.78%** |
| **WSS** | —（精选信号，主用于择时） | WSS>0 做多、<0 做空，2010-2024.6 **年化收益 25.04%**，个股年均信号切换 8.90 次 |

**结论**：WSO 作为横截面选股因子较弱，但事件形态的**时序择时**价值显著，经过胜率/赔率筛选的 WSS 把年化从 16.78% 提升到 25.04%。

## 四、学术文献对照与延伸（与研报互补）

研报是规则 + sigmoid 的"白盒"方案。以下学术方向可作为升级路径，但**与研报"概率云"概念不同，勿混淆**。

### 4.1 事件识别的机器学习升级

**[Long Short-Term Memory Pattern Recognition in Currency Trading](https://arxiv.org/abs/2403.18839)** — Jai Pal (2024), arXiv:2403.18839。
- 用 CNN（空间形态）+ LSTM（时序）识别威科夫**吸筹**结构（trading range、secondary test），sigmoid 输出形态存在概率。
- **对照**：和研报殊途同归——都用 sigmoid 输出"事件概率"，但研报用**手工公式**，本文用**学习的网络**。可作为把研报硬编码公式替换为可学习模型的参考。

**Wyckoff Schematics: Visual templates for market timing decisions** — Pruden & von Lichtenstein (2006), *Market Technician*。
- 把吸筹/派发示意图模板化，指出"同一事件有多种变体"——正是研报需要用概率而非硬规则的理论依据。

**Wyckoff Proofs: Tests, Testing & Secondary Tests** — Pruden (2009), *IFTA Journal*。
- 把"test"视为对供需假设的证伪实验，目的是"降低亏损概率"——与研报用胜率筛选 WSS 信号的思路一致。

### 4.2 价格分布预测（真正的"概率锥"，研报未涉及）

> 若想在研报基础上**进一步**做"事件发生后未来价格落在哪、概率多少"的预测锥，可用下列方法。这是研报概率云的**延伸**，不是同一件事。

- **Conformal Time-Series Forecasting** — Stankevičiūtė, Alaa et al. (2021), *NeurIPS*：分布无关、有覆盖保证的时序预测区间。
- **Ensemble Conformalized Quantile Regression** — Jensen, Bianchi et al. (2022), *IEEE TNNLS*：分位数回归 + 保形校准，直接产出多分位"云"。
- **Conformal Prediction for Time Series** — Xu & Xie (2023), *IEEE TPAMI*：处理时序非交换性。
- **Temporal Conformal Prediction (TCP)** — Aich et al. (2025), arXiv：专为金融时序的自适应风险区间。

## 五、对本项目的可落地启发

1. **WSS 因子可直接复刻**：A股 long-only 场景下，研报的做空部分用不了，但**多头择时信号**（吸筹/SOS/超卖 → +1）可作为选股池的**时序过滤器**或打分加成，叠加到现有 alpha158_hk 流程。
2. **事件公式是白盒、易实现**：第 2.3 节全部公式仅依赖 OHLCV + MACD + 波段端点，无需训练，适合先做一版规则引擎验证再考虑 ML 升级。
3. **胜率/赔率筛选是关键**：WSO→WSS 的提升说明，原始事件打分（IC 0.07）较弱，**必须经过历史胜率/赔率筛选**才有用。复刻时务必加这一层（≥100 次样本、胜率≥55%、赔率≥1.08）。
4. **校准与防过拟合**：研报统计区间 2010-2022、回测到 2024.6，存在样本内调参嫌疑；落地时应做**滚动样本外验证**，并用第 4.2 的 conformal 方法检验信号置信度是否校准。
5. **"概率坍缩"阈值 60% 是超参**：可在本项目数据上重新网格搜索这个阈值与半衰期（10 日）、形态位个数（6）。
