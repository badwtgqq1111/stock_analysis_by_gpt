威科夫点数图（Wyckoff Point and Figure Chart）
威科夫点数图（Wyckoff Point and Figure Chart）是技术分析中的一种经典工具，由理查德·威科夫（Richard D. Wyckoff）在20世纪初提出，结合其市场理论用于识别价格趋势、市场供需关系及机构资金动向。以下是关于威科夫点数图的详细论述：

一、点数图的基本概念
点数图（Point and Figure Chart） 与传统K线图或条形图不同，它忽略时间因素，仅关注价格变动幅度，通过“X”和“O”符号记录价格涨跌：

X列：代表价格上涨。
O列：代表价格下跌。
格值（Box Size）：每个“X”或“O”对应的最小价格变动单位（如1美元、10点）。
转向值（Reversal Amount）：触发价格方向反转所需的最小反向波动（通常为3格值）。
示例：若格值为1美元，转向值为3格，则价格需反向波动3美元（3格×1美元）才会新增一列。

二、威科夫理论的核心原则
威科夫方法基于以下核心思想：

市场由“聪明钱”（机构）主导：价格波动反映机构吸筹（积累）或派发（抛售）行为。
供需法则：价格趋势由供需失衡驱动，通过分析成交量与价格关系可预判趋势变化。
市场阶段：
吸筹（Accumulation）：机构低价买入，市场处于底部。
上升趋势（Markup）：需求主导，价格持续上涨。
派发（Distribution）：机构高价抛售，市场见顶。
下降趋势（Markdown）：供应过剩，价格下跌。
三、威科夫点数图的独特应用
点数图在威科夫理论中被用于识别市场结构和机构意图，关键分析方法包括：

1. 支撑与阻力识别
水平支撑/阻力：通过横向密集的X/O列识别关键价格区域。
上升/下降趋势线：连接高点或低点形成的45度趋势线，判断趋势强度。
2. 趋势反转信号
双顶/双底突破：点数图上突破前期高点（X列）或低点（O列）预示趋势反转。
扩散形态（Spread）：价格波动范围扩大，可能标志吸筹或派发阶段。
3. 威科夫经典形态
弹簧效应（Spring）：价格短暂跌破支撑后快速反弹，标志吸筹结束。
跳跃效应（Jump）：价格突破阻力后快速拉升，确认上升趋势启动。
派发区间：高位震荡伴随成交量萎缩，显示机构抛售。
四、威科夫点数图的实战步骤
确定市场阶段：

吸筹阶段：价格横向震荡，成交量在下跌时缩小，上涨时放大。
派发阶段：价格高位盘整，上涨时成交量萎缩，下跌时放量。
分析供需关系：

需求强劲：X列高度增加，回调（O列）浅且短暂。
供应主导：O列高度增加，反弹（X列）无力。
结合成交量验证：

价格上涨伴随高成交量：确认需求真实。
价格下跌伴随低成交量：可能为诱空陷阱。
制定交易计划：

入场点：突破吸筹区间上沿或回调至支撑位。
止损点：设置在关键支撑/阻力下方或上方。
目标位：根据区间高度或趋势线推算。
五、优缺点分析
优点：
过滤市场噪音，聚焦价格本质。
直观显示供需变化，适合中长期趋势分析。
帮助识别机构行为，提升交易胜率。
缺点：
滞后性：需较大价格波动才能触发转向，短线交易不适用。
参数依赖：格值与转向值的选择影响形态识别，需经验调整。
需结合其他工具（如成交量、K线形态）综合判断。
六、参数设置建议
格值（Box Size）：通常取价格波动的1%-3%，如标普500指数可用5点。
转向值（Reversal）：常用3格值，波动大的市场可调至2格值以提高灵敏度。
七、案例分析：吸筹阶段识别
价格形态：长期横盘，多次测试支撑（形成“弹簧”）。
成交量特征：下跌时缩量，突破时放量。
点数图信号：X列突破震荡区间上沿，O列回调幅度有限。
八、总结
威科夫点数图是结合价格、成交量与市场心理的综合分析工具，尤其适合捕捉中长期趋势转折点。其核心价值在于通过价格行为揭示“聪明钱”动向，帮助交易者与机构同步操作。掌握该方法需长期实践，建议结合威科夫的“复合操作员理论”（Composite Operator）与市场周期理论深化理解。

- O列：价格下跌超过格值时向下填充
- 仅记录有效突破，忽略回撤。	- 每根K线包含开盘价、收盘价、最高价、最低价
- 按固定时间间隔生成（如日K线）。

2. 参数设置敏感（格值与转向值需优化）
3. 需结合成交量验证突破有效性。	1. 短期波动噪音多，易产生误导信号
2. 形态解读主观性强（如“十字星”需结合背景）
3. 中长期趋势识别滞后。
关键公式/算法	- 目标价公式：目标价 = 突破位 ±（横向格数 × 格值）
- 转向规则：反向波动≥转向值×格值时换列。	无特定公式，但衍生指标如：
- 移动平均线：MA(n) = (Σ收盘价)/n
- 布林带：中轨=MA(20), 上下轨=中轨±2σ。
典型买卖信号	- 买入信号：三重顶突破、上升基底突破、支撑位放量X列
- 卖出信号：三重底跌破、下降顶部、阻力位缩量O列。	- 买入信号：锤子线、启明星、突破均线
- 卖出信号：吊颈线、黄昏星、均线死叉。
适用场景	1. 中长期趋势交易
2. 机构资金动向分析（积累/派发）
3. 波动率较高的市场（如期货、加密货币）。	1. 短线交易与日内交易
2. 市场情绪实时判断
3. 结合量价分析验证形态有效性。
经典形态案例	威科夫点数图形态	K线形态
补充说明
参数设置建议：

点数图：股票常用格值为价格区间的1%-3%，加密货币可放大至3%-5%；转向值通常为3格。
K线图：短期交易选1小时以下周期，中长期选日线或周线。
组合应用策略：

趋势确认：用点数图识别大方向，K线图选择入场时机。
形态验证：点数图的突破信号与K线的放量阳线结合，提高胜率。
历史局限性：

点数图对突发新闻（如政策变化）反应滞后，需结合基本面分析。
K线图在极端行情（如闪崩）中易产生“毛刺”，需过滤异常值。

威科夫点数图与传统K线图的对比
逻辑、优势、缺点、参数、公式及买卖点等核心维度：

维度	威科夫点数图	传统K线图
底层逻辑	基于供需关系，通过X/O符号记录价格变动，过滤短期噪音，突出趋势与支撑阻力。	基于时间周期，展示开盘/收盘/最高/最低价，反映多空力量对比与市场情绪。
核心优势	1. 趋势清晰：过滤日内波动，直接展示多空力量平衡点。
2. 支撑阻力可视化：密集成交区（X/O重叠）一目了然。
3. 目标测算：通过“因果关系”计算价格目标。	1. 信息全面：包含时间轴与价格细节，适合短期交易。
2. 形态丰富：如十字星、吞没形态等提供直观反转信号。
3. 量价结合：成交量辅助验证趋势强度。
主要缺点	1. 滞后性：需价格突破确认后才发出信号。
2. 忽略时间：无法捕捉事件驱动型波动。
3. 参数敏感：不同Box Size可能导致信号差异。	1. 噪音干扰：短期波动易掩盖长期趋势。
2. 主观性强：形态识别依赖经验（如头肩底需确认颈线）。
3. 多指标依赖：需结合均线、MACD等综合判断。
参数与公式	- Box Size：代表每个X/O的价格单位，通常为ATR×0.5-1.5。
- Reversal Size：转向单位，默认3倍Box Size。
- 目标测算：目标价=突破位+（形态高度×Box Size）×1.618。	- 时间周期：如日线、周线、1小时线等。
- 技术指标：
- 均线：SMAₙ=∑价格/n。
- RSI=100-100/(1+平均涨幅/平均跌幅)。
- MACD=EMA₁₂-EMA₂₆。
买卖信号	1. 突破买入：价格突破水平阻力位（密集成交区），成交量放大。
2. 形态反转：头肩底颈线突破、矩形整理突破。
3. 量价背离：价格新高但X列稀疏（需求不足）。	1. 蜡烛形态：早晨之星（见底）、乌云盖顶（见顶）。
2. 趋势线突破：上升趋势线跌破或下降趋势线突破。
3. 指标交叉：MACD金叉/死叉、RSI超买/超卖。
典型应用场景	- 中长期趋势跟踪：如股票、大宗商品的月线分析。
- 低波动市场：加密货币需放大Box Size过滤噪音。	- 日内交易：捕捉短期波动（如外汇、期货）。
- 事件驱动：财报、政策发布后的即时反应。
经典案例	- 比特币2019年吸筹：通过点数图测算目标价=38×100+7800=11600，实际涨幅达46%。	- 苹果公司2023年突破：长阳突破年线，配合成交量放大，触发买入信号。
与其他工具结合	- 成交量：突破时需20日均量的1.5倍以上。
- 波浪理论：识别推动浪与调整浪。	- 资金流向：大单净流入验证上涨动力。
- 新闻事件：政策利好强化趋势信号。
关键差异总结
时间维度：

威科夫点数图完全忽略时间，仅关注价格变动序列，适合长期趋势分析。
K线图严格依赖时间周期，可捕捉短期波动，但需结合多指标过滤噪音。
信号滞后性：

威科夫点数图需突破确认（如3点转向），可能错过部分行情，但信号稳定性高。
K线图实时反映价格，但假突破（如诱多/诱空）风险较高。
参数敏感性：

威科夫点数图的Box Size直接影响图表形态，需根据市场波动性动态调整（如加密货币用较大单位）。
K线图的时间周期选择相对固定（如日线、周线），但不同周期可能导致趋势判断矛盾。
量价关系：

威科夫点数图隐含成交量（密集成交区代表多空博弈），但无具体数值。
K线图明确显示成交量柱，可结合OBV、成交量均线等指标分析。
实战建议
趋势交易者：优先使用威科夫点数图识别长期方向，结合K线图确认短期入场点。
短线交易者：以K线图为主，利用威科夫点数图过滤无效波动（如在点数图突破后再用K线形态确认）。
参数优化：
威科夫点数图：动态调整Box Size（如ATR×0.8），转向单位设为3-5倍Box Size。
K线图：组合多周期（如日线看趋势+4小时线找入场），搭配MACD、RSI辅助决策。
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# ======================
# 1. 模拟价格数据生成
# ======================
def generate_price_data(
    start_price=100, 
    n_steps=500, 
    volatility=0.02
):
    """生成随机游走价格序列"""
    returns = np.random.normal(0, volatility, n_steps)
    prices = start_price * np.exp(np.cumsum(returns))
    return prices

# ======================
# 2. 点数图转换逻辑
# ======================
def pnf_transform(prices, box_size=2, reversal=3):
    """将价格序列转换为点数图数据结构"""
    chart = []
    direction = None  # 当前列方向：'X'或'O'
    current_col = []
    extreme = prices[0]  # 当前列的极端价格

    for price in prices:
        # 尚未确定方向时的初始化
        if not direction:
            if price >= extreme + box_size:
                direction = 'X'
                extreme = price
                current_col = [extreme]
            elif price <= extreme - box_size:
                direction = 'O'
                extreme = price
                current_col = [extreme]
            continue

        # 处理当前列方向
        if direction == 'X':
            if price >= current_col[-1] + box_size:
                while price >= current_col[-1] + box_size:
                    current_col.append(current_col[-1] + box_size)
                extreme = max(extreme, price)
            elif price <= extreme - reversal*box_size:
                chart.append(('X', current_col))
                direction = 'O'
                extreme = price
                current_col = [extreme]
                
        elif direction == 'O':
            if price <= current_col[-1] - box_size:
                while price <= current_col[-1] - box_size:
                    current_col.append(current_col[-1] - box_size)
                extreme = min(extreme, price)
            elif price >= extreme + reversal*box_size:
                chart.append(('O', current_col))
                direction = 'X'
                extreme = price
                current_col = [extreme]

    # 添加最后一列
    if current_col:
        chart.append((direction, current_col))
        
    return chart

# ======================
# 3. 可视化
# ======================
def plot_pnf(chart, box_size):
    """绘制点数图"""
    plt.figure(figsize=(12, 8))
    
    for col_idx, (direction, column) in enumerate(chart):
        x = [col_idx] * len(column)
        y = np.array(column)
        
        if direction == 'X':
            plt.scatter(x, y, color='green', marker='^', s=100)
            # 绘制垂直线连接所有X
            plt.plot(x, y, color='green', linewidth=1)
        else:
            plt.scatter(x, y, color='red', marker='v', s=100)
            plt.plot(x, y, color='red', linewidth=1)
            
        # 标注价格格值
        for price in column:
            plt.text(col_idx, price, f'{price:.1f}', 
                    ha='center', va='center', fontsize=8)

    plt.title("Wyckoff Point & Figure Chart")
    plt.xlabel("Column Index")
    plt.ylabel("Price Level")
    plt.grid(True, alpha=0.3)
    plt.show()

# ======================
# 4. 主程序执行
# ======================
if __name__ == "__main__":
    # 生成模拟数据
    np.random.seed(20)
    prices = generate_price_data(start_price=100, n_steps=500, volatility=0.015)
    
    # 转换点数图 (参数可调)
    box_size = 2.0  # 每个格子的价格幅度
    reversal = 3    # 反转格子数
    pnf_chart = pnf_transform(prices, box_size, reversal)
    
    # 可视化前20列
    plot_pnf(pnf_chart[:20], box_size)
