# P1.23 两个规则策略（底部反弹确认 / 箱体突破-回踩-再突破）与 ML 取舍

编写：2026-09-26。关联：`P1_22_cn_volume_style_oos_shap_plan.md`（数据与归因底座）、`config/cn_pipeline.toml`。

## 0. 结论先行

1. **信号生成不需要 LightGBM/Transformer**：这两个策略本身就是"状态 + 确认条件"，仓库里都已有规则实现：
   - 底部反弹确认 = `bottom_momentum` recipe（`factor_engine/signals/bottom_momentum.py`）
   - 箱体突破→回踩→再突破确认 = `donchian_pullback` recipe（`factor_engine/signals/donchian.py:59`）
2. **ML 只允许出现在三个位置**（且都必须用同一 OOS/成本口径验收）：
   - ① **信号过滤**（take/skip）：`factor_engine/ml/meta_labeling.py` 的 `apply_meta_gate`，把"这笔信号该不该做"当二分类；
   - ② **候选排序**（资金有限时买哪一只）：把模型分当作排序键之一，而不是主选择器；
   - ③ 仓位/风险缩放（波动目标）——这是风控公式，不是 ML。
3. **禁止**：把 1,284 列的横截面 ranker 当主选择器去"筛出策略票"。当前名单里出现的"便宜 + 质量 + 缩量"画像正是这种用法造成的，与这两个形态策略是两套逻辑（见 P1.22 §9.4/§9.5 的实测）。
4. **Transformer 先降级为挑战者**：同配置重复训练 OOS rank IC 的 sd≈0.093（config 注释记录），在同一口径下未证明增量。LightGBM 保留，只作为①/②的候选。

## 1. 两个策略的定义与现有证据

### 1.1 底部反弹确认（`bottom_momentum`）

现状参数（`config/cn_pipeline.toml`）：`lookback=126`、`min_rebound_atr=1.0`（自 126 日低点反弹 ≥1×ATR20）、`latest > ma20`、`relative20 > 0`（个股 20 日相对行业收益）、`min_volume_ratio=1.1`；sleeve：`slots=1`、权重 5%~10%、`rank=signal_score`、`require_market_trend_up=true`、**`min_model_score=0`（已经不依赖模型）**。

证据：事件研究（2024–2026）显示该形态**强依赖市场状态**——市场上行 +0.80%（t=17.1），下行 +0.04%（t=0.58）；sleeve 5 日超额 +0.52%。

**待补**：确认条件的"无反弹迹象"反例（我们此前观察到的"缩量但没反弹"）应写成显式排除项（例如：`close` 未站上 MA5/MA20、5 日收益未转正、相对行业强度未转正 → 不进候选），并在文档里给出参数依据。

### 1.2 箱体突破→回踩→再突破确认（`donchian_pullback`）

现状参数：`window=20`、`breakout_min_pct=0.005`、`tol_break=0.015`、`tol_low=0.03`、`tol_high=0.05`、`max_sessions_since_breakout=5`、`volume_dryup_ratio=0.70`（回踩缩量）、`volume_expansion_min=1.30`（再突破放量）、`channel_width_max=0.35`；sleeve：setup 通道 `max_overrides=2`、`forced_min_weight=0.06`、`forced_max_weight=0.20`、**`min_model_score=75`（目前仍要求模型同意）**。

证据：**裸的 20 日通道突破本身是平的甚至负的**（+1 日 +0.00%、+5 日 −0.56%），"追高即失效"：`close` 超出上沿 >5% 后 5 日超额 −0.50%（t=−2.15）、5 日累计涨幅 >20% 后 −0.32%；因此 `max_breakout_extension=0.05`、`max_runup_5d=0.20` 是必要的排除项。回踩+再确认版本（即你要的那个）sleeve 实测 5 日超额 +0.42%。

**待补**：把"回踩"定义成可检验的状态（触及通道上沿/前高附近、缩量比、回踩幅度区间、回调不破突破位），并把"再突破"定义为**放量 + 收盘价重新站上突破位**；每一段都要有独立的命中率与 MFE/MAE 统计。

## 2. ML 的决策矩阵

| 位置 | 是否用 ML | 理由 / 现有接口 | 验收 |
|---|---|---|---|
| 生成信号（何时买） | **不用** | 规则已完整定义；`bottom_momentum` 已把 `min_model_score` 设为 0 | 事件基准率（命中率/MFE/MAE/5-20 日超额）分市场状态 |
| take/skip 过滤 | **可用** | `ml/meta_labeling.apply_meta_gate`（二分类、含成本意识 `_round_trip_cost_bps`） | 同一信号集合下，过滤后净期望提升且回撤不恶化 |
| 候选排序 | **可用** | `min_model_score` 是现状实现；建议改成"排序键之一"而非硬阈值 | 与随机/按量比排序对照 |
| 仓位/风险 | 不用 ML | 波动目标/ATR 止损 | 与固定仓位对照 |
| 主选择器（横截面 ranker 选票） | **禁止** | 与两个形态无关；会再次引入"便宜+质量+缩量"画像 | — |

## 3. 实验设计（在 P2 harness 上跑，三臂）

- **A0 纯规则**：只用两个 recipe + 显式排除项 + 各自止损/时间止损。
- **A1 规则 + ML 过滤**：同一信号集合，用 meta-labeling 做 take/skip（阈值在训练折内选）。
- **A2 规则 + ML 排序**：同一信号集合，用模型分（LightGBM）作为候选排序键之一。
- 口径统一：同一可投池、同一 T+1 开盘成交假设、涨跌停/停牌约束、15/25/50 bps 成本敏感性、purge/embargo；按市场状态（上行/横盘/下行）分层报告。
- 验收：A1/A2 相对 A0 的**扣成本净期望**与**最大回撤**；两个非重叠 OOS 时段为正增量才保留对应 ML 组件。
- 附加：`limit_momentum`（涨停动量）与 `value_reversal` 作为既有的对照 sleeve，不做为新策略，但保持独立预算。

## 6. 文献边界（检索与逐篇核验见 `docs/research/rule_strategies_literature_review.md`）

用 OpenAlex `title.search` 逐篇核验了 30+ 篇（标题/年份/期刊/引用数/DOI 均来自 API），结论只取三点：

1. **突破类**：证据集中在"52 周新高 / 长周期趋势 / 时间序列动量 + 简单规则 + 过热过滤"（George-Hwang 2004；Moskowitz-Ooi-Pedersen 2011；Hurst-Ooi-Pedersen 2017；Baltas-Kosowski 2020），**不支持"任意 20 日通道突破"**——与我们自己的事件研究（+5 日 −0.56%）一致。放量确认有独立证据（Lee-Swaminathan 2000；Gervais-Kaniel-Mingelgrin 2001）。
2. **反转类**：A 股是**反转主导、动量缺失**（Liu-Stambaugh-Yuan 2019 的 CH-3 里没有动量因子；Wu 2010），但中国短期反转不稳定（Lu-Lao 2022），必须叠加状态与确认条件；且要区分"流动性冲击型反转"与"基本面恶化"（Nagel 2012；Da-Liu-Schaumburg 2013）——这正好是我们要求的"缩量止跌 + 相对强度转正"。
3. **"回踩后再突破（retest）"在学术检索里为空**（多次改写查询无结果）→ 属实务经验假设，必须自己用事件研究给基准率，不能引用文献背书；出场方面 Kaminski-Lo 2013 指出止损有效性取决于标的的自相关结构：**动量/突破型可用止损，反转型不宜用紧止损**。

对本文档 §1~§3 的三处修订建议（待确认后落配置）：
- 底部反弹的排除项补：回踩期量能收敛（缩量止跌）、连续不创新低天数、站回 MA5/MA20 与相对行业强度转正同时满足；止损改为"结构止损 + 时间止损"。
- 箱体定义收紧：通道宽度上限、箱体持续时间下限、前期触碰上沿次数；保留 `max_breakout_extension` / `max_runup_5d` 过热上限。
- ML 只做 take/skip（元标注）与候选内排序，验收含 PBO/多次试验登记与 15/25/50bps 成本敏感性。

## 7. 门禁的适用边界与替代分层（2026-09-26 结论）

用户判断："门禁的方式不太合适，有些东西描述不出来。" 这与本轮全部实测一致。门禁（4 个单点阈值按手设权重相加）**能**做什么、**不能**做什么：

| 需要描述的东西 | 门禁能否表达 | 证据 |
|---|---|---|
| 路径与持续时间（在低位待了多久、回撤持续几天） | ❌ 不能 | 只有"今天的分位/量比" |
| 形状/相位（下跌末段 vs 中段、回踩 vs 破位） | ❌ 不能 | 无状态、无相位 |
| 速度/加速度（反弹斜率、ATR 归一化动量） | ❌ 不能 | 只有"是否在 5%~30% 带内" |
| 不确定性（同为 +5.9% 距低点，含意完全不同） | ❌ 不能 | 无方差/无后验 |
| 变量间联合（缩量 × 位置 × 资金流的交互） | ❌ 不能 | 相加＝条件独立假设 |
| 跨股可比性（固定 5%~30% 带一刀切） | ⚠️ 勉强 | 应改为该股自身分布分位 |
| 状态切换时点（何时由下跌转为横盘/启动） | ❌ 不能 | 无转移矩阵/无变点检测 |
| 明显错误（ST、停牌、极端过热） | ✅ 能 | 这本来就是硬护栏的职责 |

配套实测（详见 `docs/research/continuous_state_and_phase.md` 与 `output/research/state_probability/REPORT.md`）：
- `k_high`（占 23% 权重）IC +0.008（t=1.23，IC 中位为负）；
- 状态模型末折系数：`pos120 +0.208`、`rel_ma60 +0.276` 为正、`dist_low120 −0.056` 为负 —— **贴低点是降概率**，与 `k_dist` 方向相反；文献（George-Hwang 52 周新高锚定）同向；
- 倾斜幅度 ±11 分 vs 相邻名次 0.031 分 → 无信息分项也能整体重排 Top-8；
- 门禁画像 Top-20 在 401 天走查里为 −1.87%（随机 +1.84%）。

**替代分层（三层职责分离）**

| 层 | 职责 | 保留/替换 |
|---|---|---|
| 硬护栏 | 防明显错误：ST/退市、流动性、可买性、涨跌停/停牌、**极端过热**（`max_breakout_extension`、`max_runup_5d`） | **保留**（这部分门禁是称职的） |
| 状态描述 | 用状态向量（趋势斜率/R²、区间分位、路径记忆、整段量能、均衡距离、可选相位）给出 `P(下一阶段延续)` | **替换现有倾斜** |
| 规则触发 | 两个策略的形态度量与确认条件（突破/回踩/再确认；底部反弹确认） | 见 §1 |
| 组合与风险 | 波动目标、相关性、权重上限、容量 | 保留 |

**推进顺序**

1. **轻改（可立即做）**：`k_high` 权重归零；"单日量比"→"整段累计量比"；"今天是否站上 MA20"→"近 20 日占优交易日占比"；固定带宽→自身分布分位；倾斜改为**保序**（先按模型分取 Top-N，再在池内定序）或加 ±2 分上限。
2. **中改**：状态向量 → `P(延续|状态)`（HMM/Kalman/OU + 校准），只作为**事件后的 take/skip 过滤**（P1.23 的 A1），不做全市场选股器（第一版实测：概率极值选股跑输随机）。
3. **重改**：把两个策略写成显式状态机（下跌 → 回踩 → 突破 → 确认 → 持有 → 失效），门禁退回"硬护栏"角色。

任何一层改动都必须走 P1.23 §3 的 A0/A1/A2/A3 与 P1.22 §4 的 P2 口径（两个非重叠 OOS + 成本敏感性 + 容量）。
