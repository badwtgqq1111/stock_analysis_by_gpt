## 4. 边界

1. 绩效基于**回放引擎**净值（2020-01-23 ~ 2026-09-30），与「选股日历」台账口径（决策日等权 + T+N）**不是同一套**。
2. `random5` 窗口与其它 tag 不同，横向对比注意区间差异。
3. α/β 用 rf=0 年化口径，与聚宽默认值不可逐位对齐。
4. 胜率/盈亏比按 FIFO 配对（247/503，差额是未平仓与部分成交）。
5. 绩效产物目前**手工跑**，还没接进每日流程（依赖回放，属研究步骤）。

## 5. 追问后的三处修正（同日）

### 5.1 「这页到底在讲什么？」

用户第一反应是「回测绩效没看懂，是买的指数基金的收益吗？」——
说明**页面问题不在数据，在口径没说清**。已把口径写进产物（`explain` 字段）并在页面顶部展示：

| 项 | 说明 |
|---|---|
| **策略净值** | 一个**模拟账户**：2020-01-23 拿 44,976 元，每个调仓日按 base_v1 手臂选出的票机械买入、等权持有 → 246,097 元。**不是实盘、不是基金** |
| **基准收益** | **指数本身**的涨跌（中证全指）。对应"如果那笔钱什么都不做，只买一只跟踪中证全指的指数基金"；实际基金会**略低**（指数不含管理费/申赎费/跟踪误差） |
| 执行细节 | 整手买入、停牌买不进、涨停不追高、跌停不砸盘、退市强制清算、佣金+滑点+印花税 |
| 怎么读 | 两条线归一化（起点=1），超额 = 策略 ÷ 基准 |
| ⚠️ 不是什么 | 不是实盘业绩（实盘只有 2026-08 起的 paper_account）；不是基金收益率；不代表未来 |

另把指标卡前两位改成 **起始资金 / 期末资金**（44,976 元 → 246,097 元），比 "+447%" 直观。
