# P2-34 选股结果导出到同花顺自选股（2026-10-09）

> 触发：用户问「选股结果能直接自动化到同花顺的新建日期选股么？」
> 证据：`artifacts/ths_export/`。

## 1. 能不能？分三层

| 目标 | 结论 | 说明 |
|---|---|---|
| 把名单**写入**同花顺自选股 / 选股条件 | ❌ **不能** | 同花顺不开放写接口，自选股存在账号云端 |
| 生成**可直接导入**的自选股文件 | ✅ 本轮实现 | PC「自选股 → 导入自选股」支持 txt/csv/xls，导入时可新建分组 |
| 全自动把名单送到眼前 | ✅ 已有 | `notify_selection.py` 支持 飞书/企微/钉钉/邮件/webhook |
| 让同花顺自己复现选股 | ⚠️ 只能复现**规则层** | 六层过滤可写成同花顺公式；**模型打分写不出来** |

现实路径：**自动生成格式正确的文件 → 人在同花顺点一次「导入自选股」**（~10 秒）。
完全无人值守就走推送渠道，不是同花顺。

## 2. 四个源（2026-10-08 实测）

```
holdings      3 只   002708 003018 300727                          ← PK 后给了目标权重的，实际要买
preselected   8 只   003018 300820 300727 002536 002046 603011 301448 002708   ← 生产候选池（PK 输入）
arm          10 只   603007 600288 603683 603135 002843 000888 603901 603199 603058 600749  ← 研究手臂
all          18 只   三者去重并集（3+8+10=21 → 18，3 只同时在 holdings 与 preselected）
```

一键导入用 `all`；想按策略分组就分别导入前三者。
另出 `2026-10-08_sources.csv`：一只票一行，标出出现在哪些源 + `n_sources`。

> 第一版只有两个口径，且 `all` 读错了文件（读了 `selection_history/<date>.csv`——
> 那是 selected 的归档、只含有权重的票，于是 all 也只有 3 只）。现在四个源各自读正确产物。

## 3. 输出格式（避免踩同花顺版本差异）

| 文件 | 用途 |
|---|---|
| `<date>_holdings_code.txt` | 纯 6 位代码，每行一个（PC 导入最通用） |
| `<date>_holdings_code_gbk.txt` | GBK 编码（老版本只认 ANSI，UTF-8 会乱码） |
| `<date>_holdings_code_name.txt` | 代码 + 名称（Tab 分隔） |
| `<date>_holdings.csv` | 代码,名称,权重,行业（Excel 看） |
| `latest_holdings_code.txt` | 最新一天的副本，路径固定便于每天导入同一文件 |

代码统一**剥掉 .SH/.SZ 后缀** —— 同花顺只认 6 位数字。

## 4. "一键"能做到什么程度

| 路径 | 需要你做的 | 步数 |
|---|---|---|
| **A. 一键复制 → 粘贴**（推荐） | 网页点「复制」→ 同花顺自选股 Ctrl+V | 2 步 |
| B. 下载 txt → 导入自选股 | 点下载 → 同花顺「自选股→右键→导入自选股」→选文件→新建分组 | 4 步 |
| C. 全自动（不走同花顺） | 无 | 0 步（只能推飞书/企微/邮件） |

真正的"零点击"不可能——同花顺不开放写接口。

## 5. 用法

```bash
uv run python scripts/export_ths_watchlist.py                 # holdings（默认）
uv run python scripts/export_ths_watchlist.py --scope all     # 含候选
```
或直接在网页「选股结果」页点「导出到同花顺」面板里的下载。

导入：**同花顺 PC → 自选股 → 右键 → 导入自选股 → 选文件 → 新建分组（分组名用日期）**。

## 6. 边界

1. **「导入」这一步无法自动化**（无写接口）；客户端模拟点击/内存注入属灰色手段，不做。
2. 若你的版本要求市场前缀（`sh600000`），当前文件不带 —— 先用 `_code_gbk.txt` 试；
   仍不认可以再加 `_prefixed.txt` 变体。
3. 导出的是**当天名单**。若"日期选股"指同花顺的**公式选股**，需把六层过滤改写成同花顺语法
   （模型分写不出来），这是另一件事。
