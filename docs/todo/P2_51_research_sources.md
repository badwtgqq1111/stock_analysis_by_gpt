# P2.51 灵感来源 / 知识库（挖因子时去哪儿找方向）

编写：2026-10-12。触发（用户原话）：**"关键词（方向模版有点少），输入框也太小了。因子挖掘参考，后面可以补充其他参考，
或者说知识库，灵感来源，聚宽应该也作为灵感来源，看看是不是还有其他海内外策略平台可以参考和提供灵感来源"**
（用户给了三条：QuantPedia / Seeking Alpha / FRED）。

## 0. 一句话纪律

**来源只提供「方向」，不提供「证据」。** 证据一律回到本地：IC 协议（|IC| ≥ 0.02 / BH-FDR q=0.05 / |t| ≥ 3 /
与存量字段 maxρ ≤ 0.7）→ 逐笔或组合口径的成本 → 影子 → 上线闸门。
已经吃过一次血：聚宽社区《首板涨停+回调+企稳+低吸-年化79%》→ 本地复现逐笔 **−0.62%**、累计 **−97.6%**
（`output/research/first_ban_lowxi/REPORT.md`）。所以"抄方向不抄结论"不是口号，是有账可查的规矩。

## 1. 落地形态（可扩展）

* `config/research_sources.json` —— **声明式注册表**（照 `config/strategies.json` 的既有模式）：
  `sources[]`（id / name / region / kind / url / api / cost / what / use / caution / entry）
  + `templates[]`（label / direction / source）。
  **加一条来源或模板 = 往这个文件里加一条**，不用改代码、不用重新构建。
* `GET /api/agent/research-sources`（页面左栏「灵感来源 / 知识库」与方向模板都读它；`factors/context` 里也带一份，
  保证老调用方不破）。
* 前端：左栏「灵感来源 / 知识库」= 按地区分组的 chips + 点开看 **怎么用 / 坑 / 入口** + 「用它的方向」一键填进 composer；
  方向模板从 4 条 → **12 条**（每条带来源小标签），输入框 rows 2 → **5**（min-height 120px）。

## 3. 12 条方向模板（每条绑一个来源）

小市值×量价交互（JoinQuant）／打板口径（JoinQuant）／行业中性口径（米筐·优矿）／论文复现（SSRN）／
宏观状态×行业（FRED）／基本面质量（Seeking Alpha）／资金流×换手（QuantPedia）／反转与低波（Alpha Architect）／
事件驱动（财报公告，SSRN）／算子组合探索（WorldQuant BRAIN）／波动率风险溢价（QuantPedia）／反面清单·证伪（本地反例档案）。

每条模板的 `direction` 都写清了**预测目标 + 可用字段/算子 + 要避开的坑**（与项目里"研究方向"的实际写法一致），
点一下填进 composer 后可再改。

## 5. 下一步（可继续补的来源/用法）

1. **接 RSS/API 变成"灵感日报"**：Quantocracy RSS、arXiv API、FRED API 都是机器可读的 ——
   可以每日抓标题落 `output/research/inspiration/<date>.md`，与挖掘会话联动（选中一条 → 生成方向草稿）。

   便于以后"来源 → 方向 → 因子 → 策略"全链条回溯。
