# P2.60 实盘镜像：任何时段都按行情定价（"应该根据每日分时实时更新"）

> 用户（2026-10-13）："实盘镜像里的股价应该根据每日分时，实时更新啊。
> K线自选股里的实盘镜像更新了，独立页面的实盘镜像却没有更新。"

## 一、现场：同一份持仓，两个页面两个价

截图（18:07）里独立页显示的是 **13.13 / 114.56 / 94.11 / 9.56**，价源写「快照」；
同一时刻 K 线页左侧自选（实盘镜像分组）已经是 **13.23 / 111.98 / 92.96 / 9.37**。
用户看到的就是这个矛盾。

## 二、根因：非交易时段**根本不取报价**

`backend/api/paper.py::live_realtime` 原来写的是：

```python
session = live_quotes.trading_phase()
quotes = {}
if session.get("live"):                       # ← 只在盘中取
    quotes, quote_error = live_quotes.tencent_quotes(codes)
else:
    quote_error = f"非交易时段（{session.get('phase')}），用盘后价"
```

而"盘后产物"是**当天早上 07:49** 生成的（价 = **前一交易日收盘**），
所以 15:00 之后打开页面：现价是昨天的。对比之下 K 线自选走 `/api/intraday/quotes`，
那个接口**任何时段都取一次腾讯快照**（收盘后拿到的是当日收盘价）—— 两个页面从源头就分了叉。

## 三、修法：任何时段都取报价 + 诚实口径

```python
quotes, quote_error = live_quotes.tencent_quotes(codes)     # 不再按 session 分支
basis, basis_label = live_price_basis(session, quotes)
```

`live_price_basis()`（新函数，纯逻辑、可单测）按"**报价自带的时间戳日期** + 当前时段"判定：

| 场景 | 口径 | 页面显示 |
|---|---|---|
| 盘中 am/pm/auction | `live` | 价源 **实时** |
| 收盘后且报价日期 = 今天 | `close` | 价源 **今日收盘（报价 2026-10-13）** |
| 报价日期 ≠ 今天（盘前 / 周末 / 节假日） | `prev_close` | 价源 **上一收盘（2026-10-09）** |
| 一条报价都没拿到 | `disk` | 价源 **盘后产物**（并保留 `quote_error` 说明原因） |

前端（`LiveAccount.vue`）：价源 pill 显示口径 + 报价日；「行情更新」在非盘中时显示
`（closed · 今日收盘）` 而不是过去的"用盘后价"；「盯市」改成 **4/4 条**（原来读盘后产物的
`observations` = 0，看起来像"一条都没盯"）；行情时间列直接给源时间戳（16:14:51）。

**顺带修掉一个 100× 的口径错**：K 线页侧栏 `livePct()` 把 `change_pct`（**小数** 0.0076）
当百分数打印，显示成 `+0.01%`；同页分时面板（有 ×100）显示 `+0.76%`。已统一为 ×100。

## 四、实测（2026-10-13 18:12，收盘后）

```

② 独立页：价源 今日收盘（报价 2026-10-13） ｜ 盘后产物 2026-10-13T07:49:56 · 盯市 4/4 条
```

## 五、回归锁

`test/test_live_price_basis.py`（5 条，进每日预检）：
1. 口径判断四例（盘中/收盘/盘前/无报价）；
2. **非交易时段也按报价定价**（monkeypatch `trading_phase=closed` + 假报价 → 断言
   `price_source='close'`、`priced == 持仓数`、`last_price == 报价价`）—— 这条直接钉住这次的事故；
3. 报价源失败必须退回盘后产物**并保留 `quote_error`**（不静默）；
4. 前端必须消费 `price_basis_label` + 显示"盯市 N/M 条"；
5. `livePct` 必须 ×100。
（注意：该接口有 2 秒 TTL，用例里要 `cache_clear()`，否则第二个用例会读到第一个的结果 —— 实测踩过。）

## 六、边界

* 收盘后用的是**行情源的当日收盘价**（本地日线 2026-10-13 的 bar 要等中继在 17:00~18:30 铺开；
  18:30 的每日自动化会把当日收盘写进产物，之后两个来源应当一致 —— 若不一致说明中继与行情源有差，
  页面上"价源"会明确写出用的是哪一个）。
* `asof`（账户快照日）仍是 `config/live_account_holdings.json` 里的 2026-10-12 —— 那是**持仓快照**的日期，
  不是价格日期；两者现在分别显示（快照 pill / 报价日），不再混为一谈。
* 非交易日（周末）打开页面会显示"上一收盘"，这是正确口径，不是没更新。
