# P2.70 交易拥挤度：资料总结与策略池研究计划

日期：2026-10-16  
状态：**P0首轮审计、P1研究版及P2的A/B/C/E影子已执行；D/F、完整PIT控制与独立前向业绩待完成，P3未达启动条件。**

## 一、结论先行

1. 这组资料更适合抽象成“市场/行业风险状态 + 个股交易过热标签”，而不是直接新增“高拥挤卖出、低拥挤买入”的策略。
2. 优先验证换手率历史分位、量额乖离、量价相关性、市场宽度是否给现有策略带来**超出波动率、动量、市值和行业暴露的增量信息**。极端放量既可能伴随上涨延续，也可能伴随尾部损失，方向交由样本外检验。
3. 先离线研究，再独立影子，最后只读展示。保留现有生产配置、年化收益排序与K线实盘置顶；拥挤度不抢策略池主位。

### 资料中的证据边界与待澄清问题

- **标题含估值，现有7图未展示估值择时规则或完整组合构造。** PE/PB估值扩展列为后续项，不作为本资料已验证结论。
- 表中“5日换手率、99历史分位”一行显示20日胜率81.82%、对应收益−4.76%、触发11次；“40日收盘价偏度、99分位”显示81.25%、−10.36%、触发16次。小样本且筛选参数很多；胜率究竟是下跌概率、规避成功率还是其他口径，图中未定义。
- 表格后一个收益列表头仍写“20日收益率”，紧邻“30日胜率”，存在口径疑点；图片也未给出样本期、指数范围、成本、重叠事件去重和样本外划分。因此不把81.82%等数字作为项目收益目标。
- 表格 `PrcSkew` 写“收盘价偏度”，第6图却讲“收益率偏度”；两者对象不同，后续使用不同字段并分别复现，不混称同一因子。
- 相关性页用“价涨量缩、价跌量放”解释风险，但表格出现相关性高历史分位；系数高低、近期背离、上涨阶段是三件事。先做双尾分组与趋势交互，不直接设为“相关系数越高越危险”。
- 第6图“峰度低→波动大风险高”的文字不是一般统计结论：标准化峰度不决定方差；高峰度也可能对应厚尾。其公式是**原始峰度**，不是减3后的超额峰度。实现固定口径并与CVaR、下行波动分开检验。
- 波动率页求和下标 `i=0…N` 与窗口N、分母N−1有计数歧义。项目采用N个有效收益、样本标准差 `ddof=1`，记录与图片公式的差别。
- 图片的“兴登堡预兆”是宽度代理，不等于已完整实现经典兴登堡信号；“风格指数下跌能量”只有文字，无可复现公式。

### 必须分清的概念

- **交易拥挤代理**：换手、量额异常、量价关系；不代表已观测投资者持仓。
- **持仓/筹码集中**：股东持股、机构重仓、K线筹码估算；与成交拥挤不同。股东数据按公告可得日对齐，K线估算不作独立持仓证据。
- **流动性**：成交活跃时可能更容易交易，但集中撤退时冲击仍大；高成交额不自动等于高风险或低风险。
- **组合集中/同质化**：策略重合持仓、行业偏重、收益相关性；需实际持仓与成交容量数据，不能只由单票换手推断。
- **动量/波动率**：作为控制项，检验拥挤代理是否只是换了名称。

## 四、候选指标与可复现口径

以下是**项目研究方案**，不是对图片缺失参数的补录。首轮仅保留少量预登记参数；资料中的其他参数只作敏感性分析，避免全网格寻优。

### 4.1 统一输入与时点

- `P/V/A/TR`分别表示价格、成交股数、成交额、经过单位验证的指定股本口径换手率；字段名写清总股本、流通股或自由流通股。
- 收益使用一致复权口径计算；涉及真实市值、成交容量时使用匹配时点的未复权价格/真实市值。当前QFQ回填版本保留非PIT标识，前向单独归档。
- 默认t日收盘后计算，最早t+1开盘交易。盘中日线未完成时只显示“盘中暂估”，不混入收盘历史序列。
- rolling窗口仅用截至t的信息。固定窗口、最小样本、缺失策略、单位、去极值和版本；零方差相关性/高阶矩设缺失，不填0。

### 4.2 首轮指标清单

| 优先级 | 指标 | 首轮定义与检验方式 |
|---|---|---|
| P1 | 换手过热 | `mean_5(TR)`；对过去252个有效历史值取分位，当前值只与t−252…t−1比较，完整暖窗后输出；主阈值95%，99%仅敏感性 |
| P1 | 量额乖离 | `V_t/mean_20(V)-1`、`A_t/mean_20(A)-1`；均值含t，非正分母设缺失；先单指标，不重复叠权 |
| P1 | 价格乖离 | `P_t/mean_20(P)-1`；作为超涨控制项，与换手/量额做交互，不直接混成拥挤总分 |
| P1 | 量价相关 | `corr_40(P,V/A/TR)`；40对有效观测，先看正负双尾；另做`corr_40(r,Δlog(A))`稳健性对照，避免趋势水平伪相关 |
| P1 | 波动率控制 | 20日样本收益标准差与既有EWMA预测；不重复训练新模型 |
| P1 | 市场宽度 | 相对之前252个交易日收盘价极值判断t日新高/低；并列计入规则固定，分母为当日具备完整暖窗的可比股票 |
| P2 | 高阶矩 | 60个有效日收益的`m3/m2^(3/2)`、`m4/m2^2`；收盘价偏度单独命名。尾部方向由分组检验决定 |
| P2 | 行业/风格热度 | 有PIT成分时计算行业换手、成交额占全市场比、价格动量及各自历史分位；行业成交量不简单相加比较 |
| P2 | 持仓重叠/容量 | 策略间`sum_i min(w_ai,w_bi)`、组合行业权重、持仓成交额参与率；同一时点与资金规模比较 |
| P3 | 加速上涨/估值扩展 | 补充清晰公式、数据时点与独立预登记后再研究，不塞进首轮综合分数 |

宽度公式对应第2图：`H=NewHighNum/Num`、`L=NewLowNum/Num`、`HindenburgSqrt=sqrt(H*L)`、`HindenburgHigh=H`、`HindenburgDelta=H-L`。全市场代理与行业内代理分开命名；历史成分缺失时先只做覆盖已审计的市场代理，明确股票池局限。

首轮不强行输出0—100综合分。先保留指标原值、历史分位、同日截面分位及数据质量标签；截面排名与历史分位不互相替代。用当日行业/对数流通市值控制或匹配比较，行业缺失单独分组，禁止用未来分类补齐。

## 五、验证设计与策略池接入

### 5.1 先回答是否真的有风险信息

- 按信号后的5/20个市场交易日，报告下跌概率、净收益分布、分位数、最大不利/有利变动和CVaR；说明每项从何种成交价起算。事后收益只作标签，不进入当日特征。
- 比较高拥挤与同日、相近行业/规模/流动性/动量/波动率的对照；市场宽度是全市场状态，另做按时间分块的状态检验，不伪造同日高低宽度对照。
- 分年、牛熊/震荡、市值/流动性、趋势/反弹策略分组；同时检验“拥挤+上涨延续”和“拥挤+趋势转弱”，避免预设高拥挤必跌。
- 报告触发总次数、去重事件数、日期数、覆盖股票数、缺失/删失比例；重叠持有期用交易日分块bootstrap或HAC，事件数不当独立样本量。
- 首轮建议2018—2023开发、2024—2025滚动检验、2026回顾留出；以实际覆盖审计为准。2026已有项目研究和已见案例，不称全新未见测试；真正独立证据来自规则冻结后的前向。
- 窗口/阈值在开发段冻结；多重比较作校正并完整披露失败变体。收益方向、复现差异和效应置信区间都保留。

### 5.2 配对实验矩阵

同一策略、同一决策日、同一原始名单及执行假设进行比较：

| 实验 | 改动 | 目的 |
|---|---|---|
| A 原策略 | 不加拥挤度 | 配对基线 |
| B 只加标签 | 完全不改订单 | 验证解释性，并检查B订单/净值与A一致 |
| C 软降权 | 对高拥挤标的权重乘0.5，差额留现金，不强行归一化 | 主风险控制假设；保留可能上涨的敞口 |
| D 硬过滤 | 高拥挤不新买；既有仓位不因标签自动卖出 | 比较简单过滤的收益/风险代价 |
| E 波动率基线 | 仅既有volcap；另配volcap+与C相同的拥挤规则 | 区分拥挤增量与单纯降仓降波动 |
| F 等敞口对照 | 用仅开发段校准的常数仓位匹配C的平均敞口 | 检查风险下降是否仅来自更多现金 |

首轮不做主动清仓、逆势抄底或拥挤反转新策略。行业整体热度与个股拥挤分开消融；V/A/TR同源信息不等权重复累加。

### 5.3 统一执行与评价

- 复用`config/execution_assumptions_cn.json`并冻结哈希：当前佣金2.5bp/双向、滑点3bp/双向、卖税10bp；这是项目固定研究假设，历史实际税率另作敏感性，不静默混用。
- 使用因果T+1开盘执行，整手、现金、不可成交、停牌、风险股、IPO限价例外与退市处理逐项审计；旧共享引擎覆盖不足的情形单列，不声称已全部建模。
- 组合回放报告年化净收益、最大回撤、CVaR、Calmar/Sharpe有效样本说明、换手、总费用、平均敞口、容量、错失上涨和交易失败。事件均值不代替组合净值。
- 暂定研究闸门（运行前冻结）：主样本外配对比较至少252个日收益、63个配对决策、3个有效季度；至少2/3季度风险改善；最大回撤与CVaR均不劣、至少一项改善10%，年化净收益落后不超过2个百分点；同步报告置信区间及等敞口对照。样本未满足时状态为积累中，不挑最好参数补闸门。
- 研究闸门只进入人工复核；前向留档、PIT审计、执行一致性和现有晋级协议仍需通过。拥挤度与波动率的复合变体按新冻结协议独立积累，不继承旧影子样本冒充新验证。
