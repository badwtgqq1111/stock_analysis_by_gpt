# P2.75 · 候选池二次排序方案

> 用户（2026-10-18）："策略选出来的 100 多只，我想进行二次排序，具体该怎么做？
> 用个股多空（偏多 AI 决策 + 研报证据）/ 威科夫评分 / 筹码分布评分 / 还是其他？"

## 0. 先说结论

**不要直接手拍权重上线。** 推荐两层：

| 层 | 分量 | 权重 | 能否历史回测 |
| --- | --- | --- | --- |
| 核心层（65%） | 策略先验 20% + 威科夫 25% + 筹码 20% | 65% | 能（全部由 PIT 日线/名单重算） |
| 增强层（35%） | AI 决策 20% + 研报证据 15% | 35% | **不能**（AI/研报是当前生成，历史回填会泄未来） |

上线前：核心层跑 2024–2026 候选池 walk-forward；增强层做 60–120 个交易日前向影子，
通过后才把权重固定。首版综合分只用于**候选池内排序**，不改变生产名单。

## 1. 为什么 AI/研报不能直接回测

- AI 多空是 2026-10-16 才接入每日流程的；对历史日期重跑 AI，模型会看到"今天"的信息，
  等于未来函数。
- 研报有明确的 `reportDate`，但当前 dossier 是"按今天的库"整理的；拿它回测历史决策日，
  会混入决策日之后才发布的报告。
- 因此：**核心层负责"可靠"，增强层负责"增量"**；两者分开验证，最后再合成。

## 2. 分量定义（都在当日候选池内做截面 z-score）

### 2.1 策略先验 `prior`

`prior = 命中策略数`（同一票被多条策略选中 = 共识）。原始 rank 只在单策略名单内可比，
跨策略不可直接相加。

### 2.2 AI 决策 `ai`

```
action_map = 买入 +1 / 持有 0 / 卖出 -1
ai = action_map × (0.5 + 0.5 × confidence)
```

置信度缺省 0.5。`卖出` 进风险标记（`ai_sell`），不直接剔除，交给综合分与 veto 层。

### 2.3 研报证据 `research`

```
stance_map = 偏多 +1 / 中性 0 / 偏空 -1 / 证据不足 → 缺失
strength = min(1, (bull + bear + citations) / 12)
research = stance × (0.5 + 0.5 × strength) × level_weight
level_weight = agent_checked 1.0 / auto_checked 0.8
```

可选加分：目标价相对现价的上行空间（有评级行时），但首版先不加，避免和 stance 重复。

### 2.4 威科夫 `wyckoff`

```
wso          = 事件概率云 WSO（-1~1）
event        = 当日最高似然事件的 side × prob（-1~1）
position     = (close - 60日低) / (60日高 - 60日低)
position_score = 1 - 2×position      # 低位吸筹 +1，高位派发 -1
wyckoff = 0.5×wso + 0.3×event + 0.2×position_score
```

### 2.5 筹码 `chip`

```
profit     = 获利盘比例（0~1）
concentration = (P95 - P5) / 平均成本   # 越小越集中
peak_dist  = (close - 筹码峰) / 筹码峰

chip = 0.4 × (1 - |profit - 0.5| / 0.5)   # 倒 U：极高获利盘=抛压，极低=套牢
     + 0.3 × (-concentration)             # 集中度低（集中）加分
     + 0.3 × clip(peak_dist / 0.10, -1, 1) # 价在峰上方=支撑
```

**注意**：获利盘的符号是假设，不是定论。回测时必须同时测三种变换：
单调正（获利盘越高越好）、单调负、倒 U，选验证期最稳的那个。

### 2.6 综合分

```
z_i = winsorize(component_i, 2%, 98%) 后标准化
composite = Σ w_i × z_i / Σ w_i（只对非缺失分量归一）
coverage  = 可用权重 / 总权重
```

缺失不硬凑 0：`coverage < 0.6` 的票不参与头部排名，回退到策略原始 rank。

## 3. 风险标记（不直接改分，先给页面/人工）

| 标记 | 规则 | 处理建议 |
| --- | --- | --- |
| `ai_sell` | AI 动作 = 卖出 | 不进前 10 |
| `research_bear` | 研报 = 偏空 | 前 10 需 AI 买入 + 威科夫 > 0 才保留 |
| `overheated` | 获利盘 > 90% 且 60 日位置 > 0.8 | 降权/等回踩，不追高 |
| `low_coverage` | coverage < 0.6 | 不参与头部排名 |

## 4. 验证协议（这是"可靠"的关键）

### 4.1 核心层（历史可测）

- 候选池：2024-01 至 2026-06，每个决策日的全部策略入选票（不是全市场）。
- 标签：未来 5/10/21 日相对中证500（或等权市场）的超额收益。
- 指标：候选池内 RankIC、Top20 vs 池均值超额、分五档单调性、换手、最大回撤。
- 流程：按半年滚动，训练期定权重、下一半年测试；**权重只允许非负、和=1**。
- 对照：单分量、等权、策略原始 rank、随机排序。
- 门槛：综合分 RankIC ≥ 最强单分量 + 0.5pp；Top20 超额 > 0 且两段窗口同向。

### 4.2 增强层（前向影子）

- 从 2026-10-16 起，每日记录：AI、研报、综合分、未来 5/10/21 日收益。
- 至少 60 个交易日后评估；不足 60 日只做描述，不调权重。
- 评估：增量 RankIC（加 AI/研报 vs 只用核心层）、Top20 命中率、回撤。
- 若增强层不增量：权重降到 0，保留面板展示，不进入排序。

### 4.3 防过拟合

- 预注册主指标（21 日 RankIC）与权重上限（单分量 ≤ 35%）。
- 不做"多组权重挑最好"，只比较 3 组：等权、核心层 IC 加权、人工先验（本文）。
- 所有结果全报，包括失败窗口。

`综合评分`（composite）/
`策略原始顺序`。
实盘持仓在所有模式下始终置顶，并显示它在当前模式下的候选池排名/分数。

合成分：
```
flow_score      = mean(z(5d净流入/流通市值), z(20d净流入/流通市值))
longshort_score = AI 决策 + 研报证据的增强层分数
flow_longshort_score = 0.5×z(flow_score) + 0.5×z(longshort_score)
```

## 6. 首版结果（2026-10-16，124 只候选）

候选池 = 16 条策略最新名单的并集（与 K 线左侧"全部策略"同一口径），不是只看 AI 名单。
前 10：云铝股份、圣农发展、华明装备、招商积余、贵州茅台、贤丰控股、爱美客、分众传媒、
东鹏饮料、安达维尔。

当日风险标记：`overheated` 17 只、`research_bear` 12 只（其中 2 只同时命中）。

分量相关性（Spearman）：AI/研报/威科夫/筹码两两在 -0.18~0.10，
说明它们提供的是不同信息，不是同一信号的重复。

### 6.1 核心层首次历史评估：未通过

- 样本 A（月内逐日，43 个决策日，2025-07 至 2026-01，1,563 条候选）：
  综合分 RankIC **-0.030**（t=-1.18）；Wyckoff **-0.047**（t=-1.68）；
  筹码 **-0.018**（t=-0.80）；策略先验在多数日期无截面差异（候选池内几乎都是 1 条策略）。
- 样本 B（每月最后一个决策日，15 个月，2024-01 至 2026-05；其中 7 个月有足够候选与未来数据）：
  综合分 RankIC **-0.095**（t=-1.15），Top20 相对候选池均值 **-1.32%**。
- 两个样本、两种抽样方式都未通过；不是"某一段行情"的问题。
- 结论：**当前核心层符号/权重不成立，综合分只能作为实验排序，不能作为交易信号。**
  已在前端标注"未通过验证"。
- 下一步：不要在这 43 天上调参；扩大样本到全部月度、按月滚动，
  在验证期重估每个分量的符号（尤其是 WSO、peak_dist、concentration），再测独立测试期。
