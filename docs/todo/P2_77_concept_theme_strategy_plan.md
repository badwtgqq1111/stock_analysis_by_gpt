# P2.77 概念/主题策略：从「选股规则」到「层」的落地计划

编写：2026-10-23。前置：P2.76（熵/概率）、概念排行、`concept_watch_arm` 规则版。
参考：`output/research/p2_concept_v2/{REPORT,WATCHLIST,STRONG_BACKTEST,FACTOR,BRAINSTORM}.md`

## 0. 结论先行

概念信号已经证明**不能当个股特征**（并入 B4 后 RankIC 0.1310→0.1215、过滤器三折全负），
但**当「层」用是有效的**：

- 规则版 strong + regime：2024-2026 CAGR **35.5%**、回撤 **−20.8%**、Sharpe 1.18；
- 概念因子对弱基线有 +0.016 AUC，对强模型冗余。

因此本计划只做三件事：**主题层择时、主题内排序、主题生命周期**；
不再往个股特征表里塞概念列。

## 2. 设计原则

1. **层优先**：概念只决定「选哪些主题 / 何时 / 多大仓位」，不直接给个股打分；
2. **风格中性**：概念组合先做市值/波动/行业中性化，避免只是小盘/成长 beta；
3. **PIT**：概念成员目前是当前快照，所有结论标注偏差；新数据按日快照积累；
4. **成本**：双边 15.5bp + 换手约束；任何 overlay 若换手翻倍需重新评估；
5. **单一门槛**：每个实验先定验收线，达不到就停，不无限调参。

## 3. 方案（按优先级）

### A. 概念状态 → 总仓位（P1）
- 状态量：`n_rising`（rise≥0.8 且广度≥50% 的概念数）、`breadth_median`、`heat_concentration`（前 10 概念成交额占比）；
- 仓位映射：`n_rising≥5 且 breadth_median>0.55 → 1.0`；`1~4 或 >0.45 → 0.7`；否则 `0.3`；
- 应用到：概念策略日净值、B4 影子净值、中证500；
- 验收：回撤改善 ≥5pp，CAGR 下降 ≤2pp，换手不翻倍。

### B. 主题先验 × 个股 alpha（P2）
- 先选 top3 主题，再在主题内用 B4 预测排序（而非全市场 Top20）；
- 对照：全市场 B4 Top20 vs 主题内 Top20；
- 验收：RankIC 或 20 日净超额至少一项提升 ≥10%。

### C. 主题生命周期（P3）
- 四阶段：birth（新概念/成员扩张）、acceleration（广度 40→65%）、crowding（涨停密度>15%、5日>25%）、decay（广度连降 3 日）；
- 输出阶段标签 + 各阶段未来 5/20 日收益；
- 验收：加速期正超额、拥挤期负超额，且跨年稳定。

### D. 新主题发现（P4，LLM）
- DeepSeek 对未覆盖股票打标（闭集 375 概念）+ 监控新概念/新成员增速；
- 验收：新概念首现后 5/10 日等权收益显著高于老概念。

### E. 概念网络/溢出（P5）
- 共成员矩阵 → 主题邻接；邻居热度对概念未来收益的预测力；
- 验收：邻居热度因子 RankIC ≥0.02 且 t>2。

### F. 拥挤度防守（P6）
- 拥挤分 = 涨停密度 + 成交额占比分位 + 换手分位；用于减仓/剔除；
- 验收：高拥挤组下一期回撤显著大于低拥挤组。

## 5. 验收门槛（统一）

- 回测：2024-2026 + 2025-2026 两段都要正超额；
- 风险：最大回撤不劣于基线 2pp 以上；
- 稳定：分年不出现单年依赖（任一年超额为负需解释）；
- 可执行：换手、涨跌停、停牌、整手至少做一次敏感性。
